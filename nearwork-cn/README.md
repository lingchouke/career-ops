# 近职求职助手
在项目文件夹里双击「启动近职」。如果你在代码目录里打开本说明，请双击同目录的 start.cmd。

1. 上传能复制文字的 PDF、Word（DOCX）或文本简历。输入工作城市，选择公司所属行业，填写岗位关键词，然后点「查找岗位」。关键词可以留空。
2. 列表按匹配度从高到低排列，显示岗位、公司、地点和匹配度。点一行进入该岗位。结果来自目前接入企业的公开招聘页；没有结果时，可以返回放宽关键词或行业。
3. 先看顶部的匹配度和理由，再看已满足项旁边引用的简历原文。「欠缺项」表示目前材料尚未证实。必须条件和加分条件分别列出，招聘方没说明性质的要求另列。每项都有补充经历或学习的建议。返回列表可以继续比较其他岗位。

简历在本机读取和比对，关闭后需重新选择文件。匹配度是根据招聘信息和简历内容做的初步判断。英文职位以中文要点展示，可按「查看招聘方原文」核对。
